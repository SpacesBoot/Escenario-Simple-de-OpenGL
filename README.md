# Escenario-Simple-de-OpenGL
Este projecto lo hize ayer y lo subi hoy es un simple escenario, con 4 objetos, una esfera que no es esfera, un cubo , una piramide y una casa. La camara tiene controles orbitales tipo los de three js. Espero les guste ;).
